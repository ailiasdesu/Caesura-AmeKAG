# 2026-08-12-001 — KAG3 脚本导入器（P1，市场分析路线图）

## 背景

市场分析（`docs/design/engine-market-analysis-2026-08-06.md` P1 #4）指出：
**KAG3 脚本导入器是生态撬点**——KiriKiri/KAG3 已停更，其存量 `.ks` 脚本
（XP3 归档内数以万计的场景文件）没有现代迁移路径。Caesura 的 tokenizer
已是 KAG3 语法超集、运行时已有兼容别名层，缺的是一个**批量转换工具**：
把存量 KAG3 `.ks` 拉进来，转换成 KAG Neo-Genesis 可运行格式并给出
转换报告（哪些转换了、哪些不支持需要人工处理）。

## 现状调研（2026-08-12）

- `scripts/tokenizer.lua`：KAG3 语法超集解析（`[cmd param=value]`、裸参数、
  `*label`、`;` 注释、`[iscript]` 块、`"""` blocktext），`parse_with_offsets`
  提供字节偏移（行号定位）
- `scripts/kag.lua`：运行时 KAG3 兼容别名层（r/s/delay/clear/ct/endtag/
  endform/g/fadeout/ld/shake/quake/playstop/voice/se/bgm/play/waitclick/
  waitforclick/sel/select/endselect/voice_wait 等）
- `scripts/kag/expr.lua`：TJS→Lua 表达式翻译（`&&`→`and`、`||`→`or`、
  `!`→`not`、`!=`→`~=`、三目），`expr.translate` 为纯函数可独立调用
- `scripts/kag/schema.lua` 插值：支持 `$f.name` / `%f.hp%` / `${expr}`；
  **不支持 KAG3 文本嵌入 `&f.hp`**（会原样显示）
- `scripts/scheduler.lua`：未知命令降级为文本（`[WARN] unknown KAG command
  '%s' treated as text`）——KAG3 特有命令会静默显示为对话，必须由导入器
  提前发现
- 工具模式范例：`scripts/ks_check.lua`（纯 Lua CLI + 测试 require + CI 门禁）

## 设计

### 形态

纯 Lua CLI 工具 `scripts/kag3_import.lua`（零 C++ 依赖，不动模块边界/接口，
无耦合度风险），遵循 ks_check.lua 模式：

```
lua scripts/kag3_import.lua <scene.ks> [more.ks ...]      # check 模式（默认）
lua scripts/kag3_import.lua -o out/ <scene.ks> ...        # convert 模式
lua scripts/kag3_import.lua --strict <scene.ks>           # 不支持命令退出码 2
```

### 转换规则

1. **命令映射表**：
   - 引擎已支持的命令（契约 78 + 流程命令 + 兼容别名）→ 保留原样
   - KAG3 特有但引擎有明确等价物的 → 静态重写（best-effort，报告说明）
   - KAG3 特有且引擎无等价物的 → 报告"不支持"（带行号），不静默
2. **`&var` 文本嵌入**：文本 token 与插值参数中的 `&f.x`/`&tf.x`/`&sf.x`/
   `&mp.x`/`&lf.x` → `%f.x%`（引擎 schema 插值语法）
3. **TJS 表达式参数**：`exp=`/`expr=`/`cond=` 参数经 `expr.translate`
   静态翻译为 Lua 语义（`&&`→`and`、三目等），输出脚本不再依赖运行时翻译
4. **`[iscript]` TJS 块**：TJS 代码无法自动转换 → 标记"需人工审查"（行号）
5. **`%var%` 插值与宏**：保留原样（引擎已支持）
6. **convert 模式输出**：基于 `parse_with_offsets` 的 offset 区间重建——
   token 区间重写，token 之间的注释/空白保留原文，输出文件不丢注释

### 报告（check 模式，stdout）

每文件：token 统计（命令/文本/标签/iscript）、转换清单、不支持命令清单
（行号 + 建议）、iscript 人工审查提示；退出码 0/1（解析错误）/2（--strict
且存在不支持命令）。

### 测试

`tests/scripts/test_kag3_import.lua`（注册进 `run_lua_tests.lua`）：
- `&var` 嵌入转换（文本 token、参数内）
- TJS 表达式翻译（if/eval 参数）
- 命令映射表命中/未命中
- 不支持命令报告带行号
- convert 重建保留注释/空白、输出可被 tokenizer 重新解析
- 退出码逻辑（--strict）

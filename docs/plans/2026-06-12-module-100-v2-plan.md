**IU F2.1:** 创建不透明句柄类型
- `src/render/api/RenderTypes.h` 定义：
  ```cpp
  struct Rgba8 { uint8_t r,g,b,a; };
  struct TextureId { uint32_t id = 0; };
  struct ProgramId { uint32_t id = 0; };
  ```

**IU F2.2:** 替换接口中的 bgfx 类型

- `bgfx::ProgramHandle` → `ProgramId`
- 更新所有消费者（RenderBinding/KAGBinding/VFXBinding/LayerManager）

**IU F2.3:** 消费者适配 + 测试

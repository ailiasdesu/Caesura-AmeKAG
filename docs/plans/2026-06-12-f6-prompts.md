## Step 2: 场景渲染

```
修改 render()：

1. 如果没有 active scene → return
2. SceneData& scene = m_scenes[m_activeScene]
3. 设置视图：
   bgfx::setViewRect(MINIGAME_VIEW_ID, 0, 0, 1280, 720)
   bgfx::setViewClear(MINIGAME_VIEW_ID, BGFX_CLEAR_COLOR | BGFX_CLEAR_DEPTH, 0x303030ff)
4. 设置变换（单位矩阵，后续可扩展）：
   float view[16], proj[16];
   bx::mtxIdentity(view);
   bx::mtxOrtho(proj, -1.0f, 1.0f, -1.0f, 1.0f, 0.1f, 100.0f, 0.0f, bgfx::getCaps()->homogeneousDepth);

5. 绑定 + 提交：

   bgfx::setState(BGFX_STATE_DEFAULT | BGFX_STATE_CULL_CW);
   bgfx::submit(MINIGAME_VIEW_ID, m_minigameProgram);

注意：m_minigameProgram 需要从 EmbeddedShaders_MiniGame 初始化
- init() 中添加 shader 初始化
```

## Step 3: 场景卸载与清理

```
修改 unloadScene(uint32_t handle) + shutdown()：

unloadScene:
- auto it = m_scenes.find(handle)
- if (it != m_scenes.end())
    bgfx::destroy(it->second.vbh)
    bgfx::destroy(it->second.ibh)
    m_scenes.erase(it)

shutdown:
- for (auto& [id, scene] : m_scenes)
    bgfx::destroy(scene.vbh)
    bgfx::destroy(scene.ibh)
- m_scenes.clear()
- m_activeScene = 0

- 提交
```

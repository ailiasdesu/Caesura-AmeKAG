## ① 定位与目标

- **地位**：产品化总任务书 Phase4（官方旗舰作品，30-90min/2-4 角色/多结局/语音/Live2D/Steam 成就）的**前置旗舰**——用一部完整可玩的短篇证明引擎闭环质量，为 Phase4 旗舰的制作与发布流程铺路。
- **性质**：先立项、不开工。029:37 明确「前置：工件 A 首版 + Sprint6-L2 收官；规格评审通过后才排制作」。
- **Web = 第一公开展示平台**（029:36 原文：「发布目标：Windows + Web（第一公开展示平台）+ Android」）的含义：
  - Web 是**首个公开可见**的展示形态——无需安装、链接即玩，承担「陌生人 30 秒内看到并以引擎做的作品」这一 Phase4 里程碑①的前置曝光；
  - Web 定位是可玩作品展示，而非商店分发（Store 级=Sprint7，见 platform-support-matrix [S]——Web 无 Store 承诺）；
  - Windows/Android 与 Web 同版本发布，但公开节奏（先 Web 或同步）为⑦用户决策位。
- **目标句**（草案）：评审通过后，按该规格制作一部 15-30 分钟、2-3 结局、含 Live2D/CJK/i18n/存档/音频/转场/VFX 的短篇作品，并在 Windows+Web+Android 三平台完成可玩发布包验证（平台矩阵对应格转 ✓）。

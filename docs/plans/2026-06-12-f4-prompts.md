## Step 1: 修复 RenderBinding 空路径保护

```
文件：src/script/bindings/RenderBinding.cpp

问题：load_texture("") 调用链最终到 TextureManager::loadTexture("") → stb_image 打开空路径 → 崩溃。

修复：
- 在 RenderBinding 的 load_texture Lua 绑定函数开头添加：
  const char* path = luaL_checkstring(L, 1);
  if (path == nullptr || strlen(path) == 0) {
      lua_pushinteger(L, 0);
      return 1;
  }
- 提交
```

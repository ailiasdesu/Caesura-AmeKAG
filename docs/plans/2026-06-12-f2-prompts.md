## 缺口

3 个 api/ 接口文件暴露 bgfx 具体类型，共 8 处：

| 文件 | 暴露类型 | 方法数 |
|------|---------|--------|
| ITextureManager | bgfx::TextureHandle | 6 |
| ILayerManager | bgfx::TextureHandle, bgfx::ProgramHandle | 2 |
| IVideoPlayer | bgfx::TextureHandle | 1 |

这违反了 AGENTS.md 第 7.3 条："禁止在接口中暴露实现细节"。

## Step 1: 创建不透明句柄类型

```
- 创建 src/render/api/RenderTypes.h：
  #pragma once
  #include <cstdint>
  
  namespace Caesura {
  struct TextureId { uint32_t id = 0; bool valid() const { return id != 0; } };
  struct ProgramId { uint32_t id = 0; bool valid() const { return id != 0; } };
  } // namespace Caesura
- 提交
```

## Step 2: 替换接口中的 bgfx 类型

```
- ITextureManager.h：
  bgfx::TextureHandle createSolidTexture(...) → TextureId createSolidTexture(...)
  bgfx::TextureHandle getPlaceholderTexture() → TextureId getPlaceholderTexture()
  bgfx::TextureHandle getTextureHandle(uint32_t) → TextureId getTextureHandle(uint32_t)
  void getTextureSize(bgfx::TextureHandle, ...) → void getTextureSize(TextureId, ...)
  uint32_t registerTexture(bgfx::TextureHandle tex) → TextureId registerTexture(TextureId tex)

  删除 #include <bgfx/bgfx.h>，替换为 #include "RenderTypes.h"

- ILayerManager.h：
  void setTexture(LayerType, bgfx::TextureHandle) → void setTexture(LayerType, TextureId)
  void render(..., bgfx::ProgramHandle) → void render(..., ProgramId)
  同上 include 替换

- IVideoPlayer.h：
  bgfx::TextureHandle getTexture(VideoHandle) → TextureId getTexture(VideoHandle)
  同上 include 替换

- 更新实现类（TextureManager/LayerManager/VideoPlayer）：
  BgfxRenderDevice 内部维护：
  std::unordered_map<uint32_t, bgfx::TextureHandle> m_textureMap;
  std::unordered_map<uint32_t, bgfx::ProgramHandle> m_programMap;
  TextureId → bgfx::TextureHandle 转换在实现层完成
  
- 提交
```

```

      bgfx::TextureHandle tex = device->resolveTexture(texId);
```

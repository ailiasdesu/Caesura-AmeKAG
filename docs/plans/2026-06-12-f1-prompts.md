## 缺口

Engine.cpp 仍 include 两个具体头文件：
- 行 16: `#include "../render/GpuMonitor.h"`
- 行 34: `#include "../render/NullGpuMonitor.h"`

虽然 GpuMonitor 创建已从构造函数移到 initPlatformPhase()，但 include 本身仍违反"Engine.cpp 不依赖具体实现头文件"的原则。

## Step 1: 提取 createGpuMonitor 函数

```
- 在 Engine.cpp 中创建静态辅助函数：
  static std::unique_ptr<IGpuMonitor> createGpuMonitor(bool headless) {
      if (headless) return std::make_unique<NullGpuMonitor>();
      return std::make_unique<GpuMonitor>();
  }
- initPlatformPhase() 中改为：
  m_gpuMonitor = createGpuMonitor(m_config.headless);
- 提交
```

## Step 2: 分离到独立编译单元

```
- 创建 src/entry/Engine_Gpu.cpp
- 内容：仅包含 createGpuMonitor() 函数体 + 两个 include
  #include "../render/GpuMonitor.h"
  #include "../render/NullGpuMonitor.h"
  #include <memory>
  
  namespace Caesura {
  std::unique_ptr<IGpuMonitor> createGpuMonitor(bool headless) {

  添加 extern 声明或 include Engine_Gpu.h
- 更新 CMakeLists.txt：添加 src/entry/Engine_Gpu.cpp
- 构建 + 316 测试全绿 → 提交
```
